# Proyecto de EDA y Clasificación

## Descripción
Este proyecto realiza un análisis exploratorio de datos y clasificación utilizando Python.

## Estructura del proyecto

```bash
Clasificacion-Vinos/
│
├── data/
│   └── StudentPerformanceFactors.csv
│
├── models/
│   └── mejor_modelo.pkl
│
├── src/
│   ├── eda.py
│   ├── entrenamiento.py
│   └── prueba.py
│
├── requirements.txt
└── README.md
```

## Librerías utilizadas

- pandas
- numpy
- matplotlib
- seaborn
- scikit-learn
- joblib

## Ejecución

### Ejecutar EDA
python src/eda.py

### Entrenar modelo
python src/entrenamiento.py

### Probar modelo
python src/prueba.py
